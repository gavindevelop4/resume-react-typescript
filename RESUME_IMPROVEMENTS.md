# Resume Improvement Suggestions (Senior Mobile Developer)

## 1. Summary Section

**Issues:**
- Too generic — "Experienced software developer" undersells seniority
- Last sentence ("Seeking meaningful opportunities...") is passive filler common in junior resumes

**Suggestions:**
- Lead with the actual specialization: Senior Android/Mobile Developer with X years of experience
- Call out Kotlin/Jetpack Compose and scale (10,000+ terminals) upfront as key differentiators
- Drop the last sentence entirely

---

## 2. WeVend Bullets

### Order
Leadership and architecture bullets are currently at the bottom (#8, #9). For a Team Lead role, these should come first.

### "Scheduled for deployment" wording
> "10,000+ terminals **scheduled for deployment**"

This weakens the achievement. Options:
- Drop "scheduled for" if terminals have shipped
- Replace with "10,000+ terminals across North America" if applicable

### Missing: Payment Security
Building payment systems is a strong differentiator. Senior mobile roles in fintech/embedded look for PCI compliance, secure payment flows, and encryption. Add at least one bullet covering security practices.

### Missing: Architecture Patterns
Senior candidates name their patterns. Current bullets describe *what* was built but not *how* it was structured. Add mention of MVVM, Clean Architecture, Repository pattern, etc.

### Claude Code Bullet (too vague)
> "Implemented AI-assisted development workflows using Claude Code, accelerating feature delivery and code quality across the team"

"Accelerating feature delivery and code quality" says nothing concrete. Quantify it — time saved, review cycle reduction, number of workflows automated, etc.

---

## 3. Sarku Japan — Looks Like a Gap

With no bullets, the entry shows only a title ("POS System Analyst" — not a mobile title) and a skills list. To a recruiter scanning quickly, it reads as a blank 13-month period.

**Options:**
- Uncomment and restore the existing bullets
- Rename the title to something that reads more like a developer role
- Add even one brief bullet to anchor the entry

---

## 4. Everway — Mobile Experience Is Underrepresented

React Native and Flutter work is real and relevant, but it's only visible in the skills string. The bullet:
> "Developed a crypto exchange application for iOS and Android..."

...is the only explicitly mobile bullet and it's listed last. Move it higher.

Publishing to the App Store also signals iOS experience — worth making more visible for Senior Mobile Developer applications that often expect some iOS exposure.

---

## 5. Global Skills Section

Two commonly scanned keywords missing from senior Android JDs:

- **Testing frameworks** — JUnit, Espresso, Mockito. Not mentioned anywhere on the resume.
- **Android concurrency** — Coroutines/Flow, WorkManager are already partially covered but worth making explicit.

---

## 6. Feb–Aug 2023 Gap

There is a ~6-month gap between Everway (ends Feb 2023) and Sarku Japan (starts Aug 2023). Not a dealbreaker, but worth being prepared to explain. If any freelance work or personal projects were done during that time, adding them would fill it.
